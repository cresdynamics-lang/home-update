# Home Update Furniture

Premium dining sets & sofas site for **Home Update Furniture**.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- TypeScript

## Develop

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

Design direction from the Home Update website preview: onyx / espresso / antique gold / champagne / ivory, Cormorant Garamond + Jost, WhatsApp-first conversion.
